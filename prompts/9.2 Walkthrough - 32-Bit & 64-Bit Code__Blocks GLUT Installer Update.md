# Walkthrough - 32-Bit & 64-Bit Code::Blocks GLUT Installer Update

We have updated the installer script, uninstaller script, and documentation to support both 32-bit (v17+) and 64-bit (v20+) Code::Blocks installations, auto-detect standard directories, handle custom installation drives (e.g. `D:\CodeBlocks`), and copy pre-... 32-bit/64-bit OpenGL structures (`OpenGL\32Bit` and `OpenGL\64Bit`).

## Changes Made

### 1. Installer Script
#### [install_glut_admin.bat](file:///c:/Users/gsmur/Documents/GitHub/%5Bpersonal%5D/glut_project_setup/install_glut_admin.bat)
- **Auto-Detection & Interactive Selection**: Added menu allowing users to select:
  1. `32-Bit Code::Blocks (v17+)` at `C:\Program Files\CodeBlocks`
  2. `64-Bit Code::Blocks (v20+)` at `C:\Program Files (x86)\CodeBlocks`
  3. `64-Bit Code::Blocks (v20+)` at `C:\Program Files\CodeBlocks`
  4. `Custom Path / Other Drive` (e.g. `D:\CodeBlocks`)
  5. `Auto-Detected` location
- **Directory Overlay Copying**:
  - Selection [1] automatically copies pre-... files from [OpenGL/32Bit](file:///c:/Users/gsmur/Documents/GitHub/%5Bpersonal%5D/glut_project_setup/OpenGL/32Bit) to `C:\`.
  - Selection [2] automatically copies pre-... files from [OpenGL/64Bit](file:///c:/Users/gsmur/Documents/GitHub/%5Bpersonal%5D/glut_project_setup/OpenGL/64Bit) to `C:\`.
- **Dynamic Toolchain Configuration**: Copies relevant 32-bit or 64-bit static/import libraries (`libglut32.a` / `libglut32_x64.a`), DLLs (`glut32.dll` / `freeglut.dll`), header files (`glut.h`), and fixes Code::Blocks GLUT wizard and `main.cpp` templates for the selected architecture.

### 2. Uninstaller Script
#### [uninstall_glut_admin.bat](file:///c:/Users/gsmur/Documents/GitHub/%5Bpersonal%5D/glut_project_setup/uninstall_glut_admin.bat)
- Added interactive choices to clean GLUT files from specific or all standard Code::Blocks installation directories (`C:\Program Files\CodeBlocks`, `C:\Program Files (x86)\CodeBlocks`, or custom paths), as well as System32, SysWOW64, and local project output folders (`bin\Debug`, `bin\Release`).

### 3. Documentation
#### [guide.md](file:///c:/Users/gsmur/Documents/GitHub/%5Bpersonal%5D/glut_project_setup/guide.md)
- Updated Section 3 ("Automated Interactive Setup") and Section 4 ("Custom Installation Paths / Different Drives") to explain the interactive selection menu, auto-detection, multi-architecture choices, and custom drive path handling.

# Support 32-Bit & 64-Bit Code::Blocks (v17+ / v20+) Installations in `install_glut_admin.bat`

## Overview
The goal is to update [install_glut_admin.bat](file:///c:/Users/.../Documents/GitHub/%5Bpersonal%5D/glut_project_setup/install_glut_admin.bat) to seamlessly handle both **32-bit Code::Blocks (v17+)** and **64-bit Code::Blocks (v20+)** installations, auto-detect standard installation paths on local drives, handle custom installation drives (e.g. `D:\CodeBlocks`), and integrate the predefined folder structures in [OpenGL/64Bit](file:///c:/Users/.../Documents/GitHub/%5Bpersonal%5D/glut_project_setup/OpenGL/64Bit) and [OpenGL/32Bit](file:///c:/Users/.../Documents/GitHub/%5Bpersonal%5D/glut_project_setup/OpenGL/32Bit) alongside [glut_files](file:///c:/Users/.../Documents/GitHub/%5Bpersonal%5D/glut_project_setup/glut_files).

---

## Technical Analysis & Existing State Check

### 1. `glut_files` vs. `OpenGL/64Bit` & `OpenGL/32Bit` Status
* **Current `install_glut_admin.bat` behavior**: Hardcodes `CODEBLOCKS_DIR=C:\Program Files\CodeBlocks` and exclusively copies files directly from `glut_files` (`glut.h`, `libglut32_x64.a`, `glut32.dll`, `wizard_fixed.script`, `main.cpp`).
* **Status of `OpenGL/64Bit` and `OpenGL/32Bit`**:
  * `OpenGL/64Bit` contains a mirrored directory tree:
    * `Program Files (x86)\CodeBlocks\MinGW\include` (`graphics.h`, `winbgim.h`, `GL\glut.h`, `GL\freeglut*.h`)
    * `Program Files (x86)\CodeBlocks\MinGW\lib` (`glut32.lib`, `libbgi.a`, `libfreeglut.a`, `libfreeglut_static.a`)
    * `Program Files (x86)\CodeBlocks\share\CodeBlocks\templates\wizard\glut\wizard.script`
    * `Windows\SysWOW64\freeglut.dll`
  * `OpenGL/32Bit` contains a mirrored directory tree:
    * `Program Files\CodeBlocks\MinGW\include\GL\glut.h`
    * `Program Files\CodeBlocks\MinGW\lib` (`glut32.lib`, `libbgi.a`)
    * `Windows\System32\glut32.dll`
* **Finding**: `OpenGL/64Bit` and `OpenGL/32Bit` are structured to be overlayed onto drive `C:\` for legacy path setups (`C:\Program Files (x86)\CodeBlocks` for 64-bit package setup in the repo and `C:\Program Files\CodeBlocks` for 32-bit package setup). They were **not previously configured** in `install_glut_admin.bat`.

## User Review Required

> [!IMPORTANT]
> **Key Behavioral Updates in `install_glut_admin.bat`**:
> 1. **Auto-Detection with Fallback Interactive Menu**: When launched, the batch script will automatically inspect `C:\Program Files\CodeBlocks` and `C:\Program Files (x86)\CodeBlocks`.
> 2. **Version / Architecture Choice**: The script will prompt the user to select or confirm their Code::Blocks setup:
>    * Option 1: **32-Bit Code::Blocks (v17+)**
>    * Option 2: **64-Bit Code::Blocks (v20+)**
>    * Option 3: **Custom Installation Path / Custom Drive** (e.g. `D:\CodeBlocks`)
> 3. **Copy Rules**:
>    * If Code::Blocks is at `C:\Program Files\CodeBlocks` (32-bit target): contents of `OpenGL\32Bit` will be copied to `C:\`, combined with 32-bit library files and wizard fixes from `glut_files`.
>    * If Code::Blocks is at `C:\Program Files (x86)\CodeBlocks` (64-bit target): contents of `OpenGL\64Bit` will be copied to `C:\`, combined with 64-bit library files (`libglut32_x64.a`, 64-bit `glut32.dll`) and wizard fixes from `glut_files`.
>    * If Code::Blocks is located on another drive or custom folder (e.g. `D:\CodeBlocks`), the script prompts for the custom path and installs the chosen 32-bit or 64-bit toolchain files into that path directly.

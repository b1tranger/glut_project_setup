### What Caused This?

In Command Prompt (`cmd.exe`), the `>` character is used to redirect command output into a file. 

Line 34 of [install_glut_admin.bat](file:///c:/Users/.../Documents/GitHub/%5Bpersonal%5D/glut_project/glut_project_setup/install_glut_admin.bat#L34) originally had:
```bat
echo [3/4] Copying glut32.dll as freeglut.dll, glut32.dll, glut.dll -> %MINGW%\bin...
```

Because `%MINGW%` expands to `C:\Program Files\CodeBlocks\MinGW`, CMD read `-> C:\Program` as **"write the output into a file named `C:\Program`"**. 

Inspecting the file content confirmed it contained:
> `[3/4] Copying glut32.dll as freeglut.dll, glut32.dll, glut.dll -`

Windows displays the **"File Name Warning"** dialog on startup whenever a file or folder named `C:\Program` exists because unquoted application paths (like `C:\Program Files\...`) can accidentally trigger `C:\Program` instead of `C:\Program Files`.
